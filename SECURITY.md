# Security Policy

Do not report vulnerabilities in public issues when they include credentials, tokens, private URLs,
logs, HAR captures, or personal information. Use GitHub's private vulnerability reporting feature.

Include the affected version, operating system, OBS version, reproduction steps, and impact. Redact
all KS values, stream credentials, partner/user data, and local paths. Maintainers should confirm
receipt, assess severity, prepare a private fix, and coordinate disclosure before publication.

Only the latest released version is expected to receive security fixes during initial development.
