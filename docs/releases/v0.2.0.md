# Kaltura Live 0.2.0

## Highlights

- Add independent RTMP, RTMPS, and SRT protocol selection for Primary and Backup.
- Restore the native OBS streaming lifecycle: a sole selected destination uses OBS's built-in
  streamer, while Start Both assigns Primary to OBS and starts Backup after Primary is ready.
- Keep individual Primary and Backup start/stop controls alongside Start Both and Stop Both.

## SRT streaming

- Map Kaltura Primary and Secondary SRT destinations and Stream IDs independently.
- Build the OBS SRT destination with the Stream ID in the URL and keep the OBS Stream Key blank.
- Add an SRT-only latency control with a 3000 ms default and a supported range of 250–8000 ms.
- Prevent mouse-wheel page scrolling from accidentally changing SRT latency.
- Give simultaneous SRT Backup a dedicated encoder so it begins on a keyframe with fresh MPEG-TS
  headers.
- Enforce a two-second live keyframe interval to improve Kaltura ingest compatibility and backup
  startup time.

## Diagnostics and security

- Add **Download Stream Logs…** under Advanced Logging. The focused export includes Primary and
  Backup destinations, protocols, connection settings, encoder configuration, muxer events, frame
  totals, and role-tagged reconnect attempts.
- Exclude unrelated OBS startup/module messages and redact credential, token, stream-key,
  passphrase, and SRT Stream-ID values.
- Store complete destination URLs and query tokens in the operating system credential backend.
  OBS project JSON retains only query-free destination addresses and credential identifiers.

## Interface

- Default new Kaltura outputs to RTMP and apply protocol changes automatically.
- Keep connection-details and advanced stream editors hidden while retaining managed Kaltura
  settings internally.
- Place Start Both and Stop Both above the Primary stream section.
- Retain the collapsible CEA-608 monitor behavior introduced in 0.1.3.

## Installation

- macOS 12+: Intel x86_64, Apple Silicon arm64, and Universal 2 artifacts.
- Windows x86_64 and Ubuntu/Debian x86_64 artifacts.
- OBS Studio 32.0 or newer.
- Release installers include the verified Tiny and Base English Whisper models.
- Quit OBS before installing or upgrading.

## Upgrade notes

- Existing projects and securely stored Kaltura credentials are retained.
- Previously stored SRT latency values below the supported range migrate to 3000 ms.
- Existing RTMP and RTMPS outputs default an empty stream key to 1, as required by Kaltura.

## Known limitations

- Connection-details and advanced stream editors are intentionally hidden in this release.
- Universal 2 is assembled from independently validated Intel and Apple Silicon builds.
- If Apple signing credentials are unavailable to the release workflow, macOS packages are
  published with ad-hoc/unsigned development signing and may require local approval.
