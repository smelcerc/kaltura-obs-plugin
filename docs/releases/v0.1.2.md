## Highlights

- Add native builds and packaging for macOS Intel, macOS Apple Silicon, Windows x86_64, and
  Ubuntu/Linux x86_64.
- Add a validated macOS Universal 2 archive assembled from native Intel and Apple Silicon slices.
- Replace plaintext Kaltura Session persistence with macOS Keychain, Windows Credential Manager,
  and Linux Secret Service storage.
- Refactor dependency discovery and platform behavior behind one cross-platform CMake project.

## Installation

- macOS 12+ with OBS Studio 32.0+: choose the arm64, x86_64, or Universal 2 artifact.
- Windows x86_64 with OBS Studio 32.0+: extract the ZIP into the OBS installation or portable root.
- Ubuntu/Debian x86_64 with OBS Studio 32.0+: install the attached `.deb`.
- Stop all outputs and quit OBS before installing or upgrading.

## Upgrade notes

- Existing non-secret project settings are retained.
- A legacy plaintext KS is migrated to native secure storage and removed from subsequent OBS saves.

## Known limitations

- Universal 2 is produced by merging independently compiled native slices because whisper.cpp
  configures architecture-specific CPU backends per build tree.
- Unsigned development artifacts may require local OS approval. Public macOS distribution should
  use Developer ID signing and notarization when release credentials are configured.
