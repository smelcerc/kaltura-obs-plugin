## Highlights

- Connect OBS to Kaltura with a masked Kaltura Session and asynchronous validation.
- Browse, search, sort, and page through live entries, then configure the current OBS project.
- Control Primary and Backup RTMP outputs independently and monitor each output's health.
- Generate local Tiny or Base Whisper transcription without a paid speech service.
- Insert CEA-608 captions into outgoing streams with timing, placement, alignment, and diagnostics.
- Import custom caption vocabulary from CSV and preview transcripts before going live.

## Installation

- macOS 12+ on Intel with OBS Studio 31+: download and open the attached `.pkg`.
- Ubuntu/Debian x86-64 with OBS Studio 31+: install the attached `.deb`.
- Stop all outputs and quit OBS before installing or upgrading.

## Known limitations

- The v0.1.0 macOS package is Intel-only; an Apple Silicon package is not yet provided.
- If Apple Developer credentials are not configured for the release workflow, the package is
  ad-hoc signed rather than Developer ID signed and notarized.
- Windows packages are not yet available.

## Verification

Verify downloads with the attached `SHA256SUMS.txt` and GitHub artifact attestation.
