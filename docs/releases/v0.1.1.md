## Highlights

- Fix the macOS installer so OBS discovers Kaltura Live in the signed-in user's plugin directory.
- Build the Intel package against OBS Studio 32.2.1 and its bundled Qt 6.11.1 runtime.
- Preserve all streaming, local Whisper, CEA-608, and diagnostics features from v0.1.0.

## Installation

- macOS 12+ on Intel with OBS Studio 32.2+: download and open the attached `.pkg`.
- Ubuntu/Debian x86-64 with OBS Studio 32.2+: install the attached `.deb`.
- Stop all outputs and quit OBS before installing or upgrading.

## Known limitations

- The v0.1.1 macOS package is Intel-only; an Apple Silicon package is not yet provided.
- If Apple Developer credentials are not configured for the release workflow, the package is
  ad-hoc signed rather than Developer ID signed and notarized.
- Windows packages are not yet available.

## Verification

Verify downloads with the attached `SHA256SUMS.txt` and GitHub artifact attestation.
