# Kaltura Live 0.2.1

## Highlights

- Restore the **Primary only**, **Backup only**, and **Both** destination selection in Streaming
  settings and apply the selected destination to OBS's built-in stream configuration.
- Replace the selected entry thumbnail with an interactive Kaltura player using the validated
  Partner ID and KS, selected Entry ID, and UI Conf ID `58233132`.
- Keep the plugin heading, Settings button, current-entry information, and player fixed above the
  scrolling stream and caption controls.

## Player

- Add playback controls and in-player interaction through OBS Browser Source's panel interface.
- Add **Refresh Player** to reload only the embedded player.
- Use a private loopback page rather than a data URL so Kaltura browser storage works without
  writing the KS into the OBS project.
- Size the preview at 240 × 135 while rendering a larger logical player canvas so messages and the
  full control menu remain usable.
- Add a divider under the fixed current-entry region to distinguish it from scrolling content.

## Interface

- Rename the captions section to **Live Captions (beta)**.
- Preserve independent Primary and Backup start/stop controls and skip disabled destinations when
  Start Both is used.

## Installation

- macOS 12+: Intel x86_64, Apple Silicon arm64, and Universal 2 artifacts.
- Windows x86_64 and Ubuntu/Debian x86_64 artifacts.
- OBS Studio 32.0 or newer.
- Release installers include the verified Tiny and Base English Whisper models.
- Quit OBS before installing or upgrading.

## Upgrade notes

- Existing projects and securely stored Kaltura credentials are retained.
- Open Settings once to revalidate an older saved KS if its Partner ID has not yet been stored.

## Verification

Verify downloads with the attached SHA256SUMS.txt and GitHub artifact attestations.
