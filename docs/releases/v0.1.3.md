# Kaltura Live 0.1.3

- Remove the standalone Kaltura toolbar icon from OBS while retaining the Tools menu and dock.
- Add an **Update Plugin…** button to Settings that opens the latest verified GitHub Release.
- Include uninstall support in the macOS PKG and archives, Windows ZIP, and Linux DEB/tarball.
- Require OBS to be closed before uninstalling so loaded plugin files are not removed mid-session.
- Make the CEA-608 output monitor collapsible and closed by default. Preview collection begins at
  the point it is expanded and is cleared when collapsed.
